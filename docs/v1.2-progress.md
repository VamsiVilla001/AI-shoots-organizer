# Version 1.2 development progress

This file tracks implementation on the `V1.2.0` branch. A checked foundation
means the first end-to-end slice works; it does not mean the broader product
theme is release-complete.

## 1. Best-shot and duplicate-photo ranking — in progress

- [x] Derive local sharpness and exposure scores from cached thumbnails.
- [x] Generate a perceptual photo fingerprint without modifying originals.
- [x] Group near-duplicates and select the highest-quality representative.
- [x] Show quality, duplicate-count, and best-shot badges in album grids.
- [x] Filter albums to best picks or duplicate groups and sort by quality.
- [ ] Add face-aware signals: face size, occlusion, eyes-open, and expression.
- [ ] Let editors override a chosen best shot and split/merge duplicate groups.
- [ ] Validate thresholds on representative esports shoot material.

## 2. Visual face naming directly on photographs — in progress

- [x] Click detected face boxes to name, correct, or dismiss them.
- [x] Gather a named person's known appearances into an editor-owned group.
- [x] Click or draw a box around a missed face and compare it with confirmed
  named-face references.
- [x] Preserve reviewer-drawn faces when analysis is run again.
- [x] Keep face controls visible and scrollable in short or narrow windows.
- [ ] Show reference comparisons and propagation previews before confirmation.
- [ ] Add undo for face-box and naming corrections.

## 3. Explainable match evidence — queued

- Reference-face comparison, similarity, runner-up margin, and quality context.

## 4. Outcome dashboard — queued

- Processing duration, throughput, review decisions, exports, and estimated
  manual work saved.

## 5. Faster keyboard-based reviewing — in progress

- [x] Persist 0–5 star ratings and Pick/Reject flags without modifying sources.
- [x] Rate a focused thumbnail or the current Sort selection with `1`–`5`;
  clear stars with `0`; toggle Pick with `P`; toggle Reject with `X`.
- [x] Use the same shortcuts in the full media viewer.
- [x] Filter by minimum star rating and Pick/Reject state, and sort by rating.
- [x] Show rating and Pick/Reject badges on photo, RAW, and video thumbnails.
- [x] Hover-preview videos in grids with a short activation delay and only one
  active player at a time.
- [x] Generate and cache a complete H.264 proxy through GStreamer at exactly
  512px wide, preserving source aspect ratio, source frame rate, and original
  audio as AAC. Proxies use one-second keyframes, MP4 fast-start, bounded
  decoder/encoder threads, below-normal process priority, and serialized import
  generation. They live in the separate application-managed `proxies` folder;
  source media remains untouched. Both hover and viewer playback use the proxy.
  The poster remains visible until browser-native playback is ready.
- [x] Show a thin playback timeline immediately above the thumbnail filename.
  Face-review frames remain 1280px for accurate face boxes.
- [ ] Add undo/redo and a discoverable shortcut help overlay.

## 6. Release, recovery, evaluation, and correctness — queued

- Frame-aware video recognition.
- Immediate album/timeline refresh after review decisions.
