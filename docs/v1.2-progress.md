# Version 1.2 development progress

This file tracks implementation on the `V1.2.0` branch. A checked foundation
means the first end-to-end slice works; it does not mean the broader product
theme is release-complete.

## 1. Best-shot and duplicate-photo ranking — in progress

- [x] Derive local sharpness and exposure scores from cached thumbnails.
- [x] Generate a perceptual photo fingerprint without modifying originals.
- [x] Group near-duplicates and select the highest-quality representative.
- [x] Show quality, duplicate-count, and best-shot badges in album grids.
- [x] Filter albums to best picks or duplicate groups and sort by quality.
- [ ] Add face-aware signals: face size, occlusion, eyes-open, and expression.
- [ ] Let editors override a chosen best shot and split/merge duplicate groups.
- [ ] Validate thresholds on representative esports shoot material.

## 2. Visual face naming directly on photographs — queued

- Clickable face boxes, assignment UI, propagation preview, and undo.

## 3. Explainable match evidence — queued

- Reference-face comparison, similarity, runner-up margin, and quality context.

## 4. Outcome dashboard — queued

- Processing duration, throughput, review decisions, exports, and estimated
  manual work saved.

## 5. Faster keyboard-based reviewing — queued

- Shortcuts, focus management, range selection, undo/redo, and a shortcut help
  overlay.

## 6. Release, recovery, evaluation, and correctness — queued

- Signed installers and smoke tests.
- Database backup/restore and migration recovery.
- Representative accuracy evaluation and threshold reports.
- Frame-aware video recognition.
- Immediate album/timeline refresh after review decisions.
- Independent processing and export cancellation.
- Source-folder rescan reconciliation.
